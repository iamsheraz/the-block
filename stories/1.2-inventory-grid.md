# Story 1.2 — Inventory grid

**Status:** Ready
**Estimate:** 90 min
**Depends on:** Story 1.1

## Story

Replace the Story 1.1 unstyled vehicle list with the real inventory grid. Each card surfaces the buyer's first-glance signals: condition grade (or title badge for non-clean titles), year/make/model, mileage and province, conditional price line, reserve status when relevant, and an auction time chip.

## Acceptance criteria

- **AC1** `/` renders all 200 vehicles in a responsive grid: 3 columns at ≥1024px, 2 columns at ≥640px, 1 column below.
- **AC2** Each card shows: image, condition grade badge (top-right overlay) **OR** title badge (when `title_status !== 'clean'` — title badge replaces grade badge), year/make/model/trim on one bold line, mileage and province muted, conditional price line, reserve-not-met indicator when applicable, time chip with auction status.
- **AC3** The price line copy is conditional: `"Starts at $X"` when `current_bid` is null (~56% of cards); `"Current bid $X"` when there's a bid.
- **AC4** Reserve indicator renders only when `reserve_price` exists **and** `current_bid < reserve_price`. Absent reserve never renders a "no reserve" pill.
- **AC5** Clicking any card navigates to `/vehicle/:id`.
- **AC6** Image `onError` falls back to a styled placeholder card with year/make/model text — UI never goes blank.
- **AC7** Currency renders as `$X,XXX` (CAD, no explicit code). Mileage renders as `X,XXX km`. Time remaining renders in compact form (`Ends 2h 14m`, `Ends 1d 6h`, `LIVE`, `Ended`).

## Tests

- `VehicleCard renders condition badge when title_status is clean`
- `VehicleCard substitutes title badge when title_status is salvage`
- `VehicleCard shows "Starts at" copy when current_bid is null`
- `VehicleCard shows "Current bid" copy when current_bid exists`
- `VehicleCard hides reserve indicator when reserve_price is null`
- `VehicleCard hides reserve indicator when reserve_price is met`
- `formatCurrency rounds to whole dollars, prefixes $`
- `formatMileage adds thousands separator and unit`
- `formatTimeRemaining covers <1h, 1-24h, 1-7d, ended, live cases`

## How to verify (UI)

1. `npm run dev`
2. Visit `/` — see a styled grid of 200 vehicle cards in three columns.
3. Each card has an image, badge top-right (grade or title), title line, mileage and province, price line, time chip.
4. Resize the window: at ~1023px the grid drops to two columns; at ~639px it drops to one.
5. Find a salvage-title card — its top-right badge says `SALVAGE`, not a grade number.
6. Find a card with no current bid — its price line reads `Starts at $X,XXX`.
7. Find a card with a reserve and bids below it — the "Reserve not met" indicator is visible.
8. Click any card — navigates to `/vehicle/:id` (the page itself ships in Story 1.4; until then a "Not Found" placeholder is fine).

## Watch for / Notes

- Tailwind classes belong on the components, not in a separate CSS file. Use `clsx` for conditional class composition.
- The `placehold.co` image URLs sometimes return a generic placeholder rather than the themed dark variant — the `onError` fallback should handle that gracefully so the UI doesn't look broken.
- The time chip color should match the auction status: gray for upcoming, green for live, muted for ended.
- All 200 cards render at once — no virtualization. Acceptable at this scale.
