### Completion Notes

- Bootstrap stack: React 19, Vite 6.4, TypeScript 5.7 (strict + `verbatimModuleSyntax`), Tailwind 4 via `@tailwindcss/vite`, React Router v7, Biome 1.9, Vitest 3.2.
- **Deviation from spec — `tailwind.config.js` / `postcss.config.js`:** not created. Tailwind v4's `@tailwindcss/vite` plugin replaces both. Theme config in v4 is CSS-first via `@theme {}` directives; PostCSS is no longer in the chain. Keeping the older config files would have added zero-value dead files. Surface area now lives in `vite.config.ts` (plugin) and `src/index.css` (`@import "tailwindcss"`).
- **Vitest version bump 2 → 3:** vitest 2's bundled Vite is 5.x, which collides with the project's Vite 6 (`Plugin<any>` type mismatch from duplicated `vite` copies in `node_modules`). Upgraded to vitest 3, which dedupes onto the project's Vite 6 and also dropped the 5 moderate `npm audit` advisories that vitest 2 pulled in.
- **Verification gap (closed):** Initial dev confirmed AC1 via served `<title>`, Vite transform pipeline, and built-bundle string match. The live React render was confirmed by Sheraz during the code review pass on 2026-05-11 (dev server on port 5174 — 5173 was occupied).
- **JSON import in `LandingPage`** is direct (`import vehicles from '../../data/vehicles.json'`) — this intentionally violates the "all reads go through `dataStore`" rule, but that's by design: this page exists only to prove the JSON wiring before Story 1.1 introduces `dataStore`.
