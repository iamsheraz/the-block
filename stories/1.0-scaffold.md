**Status:** Ready
**Estimate:** 75 min
**Depends on:** none

## Story

Bootstrap the project with React + Vite + TypeScript strict + Tailwind + React Router + Biome. Wire CI on every push, Vercel auto-deploy from `main`. Render a placeholder landing page to prove the data import wires end-to-end before any feature work begins.

- `biome.json`

- `src/main.tsx`, `src/App.tsx`
- `src/types.ts` — `Vehicle`, `Bid`, `BidError`, `BidResult`, `FilterState`

- `.gitignore`

## Acceptance criteria

- **AC1** `npm install && npm run dev` opens http://localhost:5173 with a landing page showing: heading "The Block — Buyer auction prototype" and subheading "200 vehicles ready" reading the count from the imported JSON.
- **AC2** `npm run verify` runs `typecheck && lint && test && build` sequentially and exits zero.
- **AC3** `Vehicle`, `Bid`, `BidError`, `BidResult`, `FilterState` are declared in `src/types.ts` matching the shape of `data/vehicles.json`. Strict TypeScript compiles with zero `any`, zero `@ts-ignore`.
- **AC4** GitHub Actions CI workflow runs verify on push and PR; build status badge in README.
- **AC5** Vercel project connected, auto-deploys from `main`. Live URL captured into a temporary placeholder in README (final README writeup is Story 1.7).
